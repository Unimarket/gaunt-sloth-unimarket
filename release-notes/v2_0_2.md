# v2.0.2

- **Security-relevant change: commands Gaunt Sloth spawns now keep your credentials by default.**
  The shell tool and custom tools used to remove API keys and tokens from a command's environment.
  They now inherit Gaunt Sloth's environment unchanged, so a command that runs `gth` itself or calls
  a model API finds its keys. A command that prints its environment now puts those keys into the
  tool result, which is sent to the model provider and saved in session history. To keep the old
  isolation, set `commandEnv.scrubCredentials` to `true` and list the variables a command may keep
  in `commandEnv.passthrough`. Scrubbing now removes every variable whose name ends in `KEY`,
  `TOKEN`, `SECRET`, `PASSWORD`, `PASSWD` or `CREDENTIALS`, and `GITHUB_TOKEN` and `GH_TOKEN` are no
  longer exempt. See
  [A spawned command's environment](https://github.com/pukeko-robotics/gaunt-sloth/blob/v2.0.2/docs/configuration/tools.md#a-spawned-commands-environment-commandenv).
